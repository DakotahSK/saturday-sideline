# Saturday Sideline idea list

Ideas Dakotah wants to keep for later. Nothing here is built yet. Ask him which one to do before starting any of them.

## Big features (suggested 2026-11-11)

1. **Real player rosters.** A full roster for every team (names, positions, class years, ratings). Unlocks player development, a depth chart, season stats and league leaders, All-Conference teams, award races based on real numbers, and seniors graduating. Biggest upgrade; plan it carefully so the save keeps working and stays under the cloud size limits (derive rosters from seeds where possible).
2. **Weekly game plan.** A short prep screen before each game: scout the opponent's tendencies, pick a focus (stop the run, protect the QB, attack a weak corner) and set practice intensity with injury risk.
3. **Coaching career mode.** Hire coordinators with styles and ratings who can get poached, field offers from bigger programs (stay or leave Averyville), coaching tree, legacy score, Hall of Fame.
4. **Deeper recruiting.** Home visits, campus visit weekends, rival schools competing for the same recruit, commitment flips, a live Signing Day show.
5. **League with friends.** Use the artifact's shared data so a friend can coach another team; the league advances on a schedule and head-to-head games count.
6. **History hall.** A page per program: title banners, all-time leaders, timeline of great seasons, coaching history, greatest games.
7. **Highlights.** Auto-save big plays, a weekly top 10 plays reel, a season-ending package for the champion.
8. **Commissioner tools.** Change playoff size, realign conferences, add expansion teams, set parity strength and schedule length from inside the game.

Pick if only one: real player rosters.
